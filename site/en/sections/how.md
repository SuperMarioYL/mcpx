A single `mcpx add` runs a four-stage pipeline inside one process: **detect** (`clients.Detect` — only config files that actually exist on disk count, never guess-write) → **backup** (a timestamped sibling file, taken only when content is actually about to change) → **idempotent merge** (`config.Merge` — touch a single server entry, write atomically) → **handshake** (`handshake.Test` — stdio subprocess + raw JSON-RPC, capped at 8 seconds). One binary, no daemon, no MCP SDK dependency.
